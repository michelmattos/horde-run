# Audio credits

The recorded impacts in this folder come from Kenney's **Impact Sounds** pack
(https://kenney.nl/assets/impact-sounds), released under CC0 1.0 (public domain).
They were trimmed and converted to 64 kbps mono MP3 for the game:

| File | Source |
| --- | --- |
| `clash-0..4.mp3` | `impactGeneric_light_000..004.ogg` |
| `hit-enemy-0..2.mp3` | `impactWood_medium_000..002.ogg` |
| `hit-player-0..2.mp3` | `impactWood_heavy_000..002.ogg` |
| `gate-break-0..2.mp3` | `impactPlank_medium_000..002.ogg` |
| `tower-down-0..2.mp3` | `impactPlate_medium_000..002.ogg` |
| `build-0..2.mp3` | `impactWood_light_000..002.ogg` |

Everything else (the music and the other effects) is synthesized in `src/audio`.
